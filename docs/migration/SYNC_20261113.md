1. **浮点 RTL 后端**：引入 Berkeley HardFloat，覆盖受支持的 IEEE binary16／binary32／binary64 标量算术、格式转换、数学操作、存储以及 PIPELINE／DATAFLOW 路径；保留第三方 BSD-3-Clause 授权和来源说明。

4. **可独立运行的验证依赖**：增加浮点、转换、数学函数、流水线、FIFO、表达式及源码修复验证器，同时补齐它们引用的源码夹具。

## 复现入口

从独立仓库根目录构建，设置库路径：

```bash
taskset -c 2 Light_HLS/Tests/Light_HLS_Top/Build.sh \
  -DLLVM_DIR=/usr/local/lib/cmake/llvm \
  -DPolly_DIR=/usr/local/lib/cmake/polly \
  -DHI_USE_LLD=OFF -DHI_LEARNER_BUILD_JOBS=4
export HI_HLS_LIB_PATH="$PWD/Light_HLS/HLS_Data_Lib"

taskset -c 0 python3 Light_HLS/Tests/run_regressions.py \
  --light-hls-top Light_HLS/Tests/Light_HLS_Top/build/Light_HLS_Top \
  --output "$PWD/runs/regressions_new" --keep-going
```

输出目录应为空或不存在；CPU 编号需在本机允许的 affinity 范围内。扩展检查的完整参数见 [extended_final.json](validation_20261113/extended_final.json)，其中绝对路径应替换为当前检出路径。

```bash
taskset -c 5 Light_HLS/Tests/Light_HLS_Top/build/Light_HLS_Top \
  Light_HLS/App/backend_floating/backend_fp_fifo.cpp dut \
  --board u250 --freq 100MHz --synthesis enable \

```
