## Build:

**Pre-requisites:**
- Ubuntu 18, 20, or 22.
- gcc >= 7.1
- CMake >=3.16
- git
- Intel SYCL compiler. The version used in this project is 2023.1.0. To install it on Ubuntu: `sudo apt install intel-basekit-2023.1.0`
- RTL simulator on the path (I used the Questa FPGA Starter Edition which is free but requires a free license). 
- To run in hardware, I used the Intel DevCloud for free to access the Altera Arria 10AX115S FPGA (Intel FPGA Devcloud has been discontinued as of November 2024). Other SYCL supported FPGA card should also works, but this requires changing the Makefiles. For example, to use the Stratix 10 Intel FPGA card instead of the Arria 10, do s/intel_a10gx_pac:pac_a10/intel_s10sx_pac:pac_s10/g on all Makefiles in the repo.

**Installation:**

The below install script downloads the intel/llvm github repo and builds it. Then it builds the passes from this repo out-of-tree.
```bash
export ELASTIC_SYCL_HLS_DIR=path/to/elastic_sycl_hls 
bash install.sh
```

The below script generates generic `compile_to_bc.sh` and `compile_from_bc.sh` scripts used to inject our passes into the SYCL compiler pipeline.
Remove undesired emu,sim,hw targets (the hw target takes a while).
The SYCL compiler is multi-pass -- it consists of multiple sub-commands 
to build a host and device binary. This script runs a full compilation in 
verbose mode, and then break up the compiler steps into constituent commands.
```bash
./scripts/compilation/gen_compile_scripts.py --targets=emu,sim
```

If you want to tun in hardware, then add the 'hw' target.
```bash
./scripts/compilation/gen_compile_scripts.py --targets=emu,sim,hw
```

## FPGA25 Benchmarks:

The repo contains a "performance.csv" file with the benchmark runtime results, and an "arria10_results" directory with quartus report files from place and route. These data were used to build Table 1 in the paper. 

To reproduce the table:

```bash
export ELASTIC_SYCL_HLS_DIR=path/to/elastic_sycl_hls 
# All files generated by the below scripts are saved to experiments/
cd experiments

# Use emu/sim if targeting emulation/cycle accurate simulation.
./build_fusion_test.py hw

# Runs the benchmarks in hardware, results saved to "performance.csv".
./run_fusion_test.py hw

# Reads "performance.csv" and generates latex table, calculating hmeans, speedups, overheads.
# Saves result to "table.txt".
./gen_latex_table.py
```
